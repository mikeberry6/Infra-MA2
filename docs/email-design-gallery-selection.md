# Outlook briefing design references

The review covered 30 dated publisher editions. Twelve earned a place in the gallery because each offered a distinct technique for a masthead, a two-paragraph opening, a deal list or a chart. The selection favors techniques that can be expressed with editable text, ordinary links, simple tables and rules.

The gallery links to the originals and illustrates each technique with an Infra-MA2 briefing. “HTML email” identifies a publisher-hosted email document. Other format labels identify the version available for inspection. Outlook paste results belong to the original Infra-MA2 layouts and require a separate client test.

During the local browser check, Axios presented a browser verification screen, the two McKinsey email pages returned an HTTP/2 error, and State Street presented an investor-location prompt. The public web reader exposed the edition content for all four entries. Their observations describe the published structure.

## Outlook verification

An archive comparison checked deal order, source destinations and YTD counts across all 40 published editions through November 21, 2026, including 505 deal entries rendered in each layout. Browser checks covered the rich clipboard, manual selection, edition switching, and phone and desktop widths. The received-message comparison in classic Outlook for Windows is pending.

Use the November 21 comparison issue for the inbox test. In Chrome, select each design and use **Copy for Outlook**. Paste into a fresh HTML message in classic Outlook for Windows using **Keep Source Formatting**. Edit a sentence in the draft, then send it to your own test inbox. Check the received message in the Windows reading pane and on a phone with remote images blocked.
